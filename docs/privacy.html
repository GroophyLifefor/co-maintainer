Privacy

Nothing is sent to us.

co-maintainer runs on your machine or your own server. This page says what it stores, where, and what leaves the machine.

Last updated 2026-11-07 · To hear when this page changes, subscribe to the newsletter.
No telemetry, no analytics endpoint, no call home.

The only hosts the product talks to are the ones you configured, plus your provider's price list when probe prices an estimate. This covers the CLI, serve and the dashboard.

This website

co-maintainer.com uses Umami for page analytics and session recordings. If you sign up for the newsletter, your email is stored by Buttondown.

What is stored, and where

Everything lives under the config and cache directories. Nothing is written into your git clone.

ItemLocationSecrets
config.jsonConfig directoryYes. Tokens, access tokens, the App private key, webhook and OAuth secrets, a scrypt password hash. Plain text, chmod 0600 where supported.
repos/<slug>/Config directoryNo. The generated guides: SKILL.md, CODEBASE.md, review guides.
cache.dbCache directoryNo. Evidence and AI job cache. It does hold sampled code and PR text from your repository.
app.dbCache directoryNo. Server state: repos, jobs, reviews, token hashes, webhook dedup.
clones/, wt/Cache directoryNo. Disposable clones and per-PR worktrees on a serve host.
tools/Cache directoryNo. Pinned helper binaries such as codegraph.

Secrets

  • config.json is the one file with plain-text secrets. On a shared or CI machine, use --env=PATH or flags and keep the file out of version control.
  • --github-app-private-key-path stores only the path to the App key, so the key never enters config.json.
  • Remote review tokens are stored as hashes. The dashboard shows a new token once and cannot show it again.
  • config list masks secrets. config get prints the real value, so treat its output as a secret.
  • A review never prints a token. Known secret shapes are redacted from provider text before it is shown.

What a review sends to the model

The diff, the review guides, the codebase conventions, the pull request title and body, and any existing review comments. Codegraph results are added as text when a tool is used. It never contains your API keys, your config.json or your GitHub credentials.

Deleting data

ToRun
Remove one repository's guides and settingsco-maintainer clear owner/repo
Also remove its fetched evidence, AI job cache, clones and worktreesco-maintainer clear owner/repo --include-cache
Do that for every repositoryco-maintainer clear all
Delete every co-maintainer data file on this machineco-maintainer uninstall
Remove the CLI itself (not data, only CLI)npm uninstall -g co-maintainer
